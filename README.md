# Math Tools Android App

This project packages the supplied single-file Kivy math app as an Android APK using Buildozer and GitHub Actions.

## Build on GitHub
1. Upload all files/folders in this project to the root of your GitHub repository.
2. Commit the changes.
3. Open the repository's **Actions** tab.
4. Open **Build Android APK** and wait for the workflow to finish.
5. Open the completed workflow run and download the **Math-Tools-APK** artifact.
6. Extract the artifact and install the `.apk` on your Android phone.

The APK is a debug build intended for personal/testing installation.
